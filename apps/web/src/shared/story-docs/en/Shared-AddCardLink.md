The quiet link right after a column's last card, «+ افزودن فرصت شغلی», Add job
opportunity, which opens the add form with that column's status already set.
It is as wide as the cards, a small grey plus before the words, both in the
secondary text colour, with no ground until the pointer is over it, when a
light grey one shows.

Its name for screen readers says which column it adds to, beginning with the
words it shows. Keyboard focus draws a blue ring inside it.

## Props

### column

The column's name, which its accessible name ends with.

### onAdd

Called when it is pressed, by pointer or by keyboard.

## Stories

### Default

The link measured against the design, its name read, and pressed.

### Hover

The pointer over it: the light grey ground.

### KeyboardFocus

Reached by Tab, with the blue ring.

### InEnglish

The same link in English, the plus on the left.

### Dark

The link in the dark scheme, in the theme's dark colours.
