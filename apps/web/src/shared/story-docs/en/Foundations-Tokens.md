The design tokens, rendered.

Not a product component. This is the Foundations page, and it exists so that a
value which has drifted from `DESIGN.md` is **visible** rather than only
assertable in a test.

## Props

### family

Which scale to render: `semantic` colours, `status` colours, `spacing`, `radius`,
or `type`.

## Stories

### Semantic

The semantic colour roles, the ones components refer to by meaning rather than
by value.

### Status

The nine status colours. These are the ones a job record's stage is drawn in, so
a drift here is visible on the board immediately.

### Spacing

The spacing scale, drawn to width.

### Radius

The corner radii, drawn as rounded blocks.

### Type

The type scale, each step rendered in its own size.
