A quiet action set in a line of text, as the interview question's «تاریخش عوض
شد»: grey text at 12, underlined, with nothing around it. The design draws its
hover the same as its rest, so nothing changes under the pointer.

The design draws it no focus either, so keyboard focus draws a three pixel blue
outline just clear of the text.

## Props

### label

What the link does, in the reader's language.

### onClick

Called when the link is pressed, by pointer or by keyboard.

## Stories

### Default

The link in Persian, measured against the design, and pressed.

### InEnglish

The same link in English.

### Dark

The link in the dark scheme, in the theme's dark colours.

### Hover

The pointer over the link, which the design leaves unchanged.

### KeyboardFocus

The link reached with Tab, wearing the focus outline.
