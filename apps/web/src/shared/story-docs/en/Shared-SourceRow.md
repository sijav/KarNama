One source of applications on the Stats page: where they came from, a blue bar
as long against the largest source's as its applications are against the
largest's, the count of them at the bar's end, and the interviews that source
brought, in grey at the far end. A single source has no bar.

In the Stats page's card the name is one line, cut with an ellipsis, and the
pointer shows it whole in a small dark label. In the window that lists every
source it takes up to three lines, so the whole name shows.

The bar only draws the count beside it, so a screen reader reads the count.

## Props

### source

Where the applications came from.

### applications

How many applications came from it.

### interviews

How many of them reached an interview.

### largest

The most applications any listed source has, which the bar is measured
against; leave it out for a single source, which has no bar.

### context

`card`, the default, the Stats page's card, or `modal`, the window of every
source.

## Stories

### Card

A row of the card measured against the design.

### SeveralSources

Three rows, each bar in proportion to the largest.

### SingleSource

A single source, with no bar.

### ALongNameInTheCard

A long name cut with an ellipsis, shown whole under the pointer.

### Modal

The window's row, the long name on up to three lines.

### InEnglish

The same row in English, mirrored.

### Dark

The row in the dark scheme, in the theme's dark colours.
