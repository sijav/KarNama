The tile at the end of the board that adds a status, and so a column: a column
is a status. A dashed box with a plus over «افزودن وضعیت».

## Props

### onAdd

Called when the tile is pressed; the board asks for the new status's name.

## Stories

### Default

The tile, measured against the design, and pressed.

### InEnglish

The tile in English.
