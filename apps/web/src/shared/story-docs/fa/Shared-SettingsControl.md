کنترل تنظیمات پوستهٔ برنامه: یک دکمهٔ آیکونی که پنجرهٔ تنظیمات را باز می‌کند.

طراحی تنظیماتی نکشیده، پس به خواست مالک محصول آیکون شد: چرخ‌دنده‌ای که مجموعهٔ
آیکون‌ها برایش از Lucide گرفت، همان خانواده‌ای که آیکون‌های خودِ طراحی از آن کشیده
شده‌اند. نامش «تنظیمات» است و راهنمایش می‌گوید چه چیزی درونش است: زبان، پوسته و
داده‌های نمونه. پنجره تا باز است تمرکز را نگه می‌دارد و وقتی بسته شود آن را به دکمه
برمی‌گرداند.
